# Происхождение графики и видео

## Иллюстрации сайта

Натюрморты подготовлены для «Атласа ароматов». Изображения статей хранятся в WebP, а подписи и альтернативный текст записаны в JSON статей. [Файлы иллюстраций](catalog/static/catalog/images/) · [Данные статей](data/articles/)

| Где используются | Файлы |
| --- | --- |
| Главная и семейства ароматов | `hero.webp`, `floral.webp`, `wood.webp`, `fresh.webp`, `amber.webp`, `gourmand.jpg` |
| Журнал | `articles/notes-pyramid.webp`, `articles/fragrance-wheel.webp`, `articles/fragrance-materials.webp`, `articles/fragrance-testing.webp`, `articles/vetiver-roots.webp`, `articles/terre-comparison.webp`. В отдельных статьях используются и иллюстрации семейств. |

## Официальные фотографии для локального показа

В учебном стенде фотографии флаконов предоставляются отдельно для локального показа. Приложение читает их из `.local/official-bottle-photos/` по манифесту `.local/official-bottle-photos.json`. Манифест хранит бренд, версию аромата, страницу товара, адрес снимка, дату сверки и ссылку на условия производителя. При отсутствии набора каталог показывает описания, а карточки используют иллюстрации семейств. Адреса и условия для дополнительной партии сохранены рядом с данными карточек. Права на фотографии принадлежат их правообладателям. [Источники и условия для дополнительной партии](data/catalog_additions/README.md#официальные-фотографии)

## Видео

Сайт показывает ролики с официальных каналов Sephora, LVMH и Hermès через встроенный плеер YouTube с расширенной конфиденциальностью. В проект входят русские аннотации и ссылки на оригиналы. Для воспроизведения в карточке нужны подключение к интернету и разрешённое владельцем встраивание. Рядом с плеером доступна ссылка на оригинал. [Демонстрационные материалы](data/demo/materials.csv) · [Статьи со встроенными видео и источниками](data/articles/)
